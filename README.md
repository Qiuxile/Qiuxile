### Currently

**[Nic](https://github.com/Qiuxile/Nic)**  
一个仓库内的项目意图账本。记录你为什么做、做到哪、砍了什么，让项目不偏航。  
`Go` · `Apache-2.0`

**[Tr](https://github.com/Qiuxile/Tr)**  
终端里的轻量 AI 翻译工具。CLI + TUI 双形态，纯 Go，无桌面/Web 依赖。  
`Go` · `Apache-2.0`

**[HKForge](https://github.com/Qiuxile/HKForge)**  
HKForge 是一个面向 Windows 平台的、基于 AutoHotkey (AHK) 生态的现代化可视化图形脚本工具。  
`C#` · `Go` · `GPL-3.0`

**[Loomlet](https://github.com/Qiuxile/Loomlet)**  
键盘流图形化脚本工作台。在无限画布上把代码框织成脚本，双手不离键盘完成切框、编辑与执行。  
`C++` · `Qt` · `Apache-2.0`
